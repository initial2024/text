# OGPROFILE02 — local voluntary budget triggered, auxiliary Gecko account slot auto-switch

This is **NOT** a platform ban-evasion or user-agent/IP/device/account-rotation proxy. User can explicitly set a local "uses per slot per UTC day" budget (1–100, not any service's officially safe quota), and explicitly opt in to automatic selection of the next unused auxiliary browser slot. Both the feature and the numeric budget are **unset by default**.

Real platform limits, HTTP 401/403/429, challenge, quota, suspicious throttling, or an unreadable risk state have priority and do not trigger a switch. The app checks the platform-scoped and original-native global risk circuits both **before** recording a user-acknowledged completion and **again** immediately before choosing the next auxiliary browser. No error-triggered requests, account retries, cookie export, browser storage copying or prompt submission. To protect a potentially generating page, the app never silently infers completion: the user must tap "本轮已完成 / 计数" to attest the auxiliary webpage is idle; only then does a count increment and, if the user budget is reached and another slot has remaining self budget, the browser switches automatically without another dialog. This is one-tap finished-turn rotation, not unattended turnover of live provider model requests.

Per-provider slot counts persist in private SharedPreferences and reset by UTC day; counts represent **only user-marked completed turns**, never inferred actual provider request traffic or security signal. All local slots over budget means stop rotation. A separate opt-in toggle and budget entry live within the isolated browser dialog. Existing original WebDriver/8787 model execution remains untouched; standalone GeckoView auxiliary login slot changes do not switch original native execution account or guarantee its login. CI covers pure-Java selection and source integration but not real GeckoRuntime/browser login continuity.

Related official GeckoView docs: https://mozilla.github.io/geckoview/javadoc/mozilla-central/org/mozilla/geckoview/GeckoSessionSettings.Builder.html
